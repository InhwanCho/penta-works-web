## 범위와 예외

- 전역 입력창은 텍스트·검색·이메일·비밀번호·전화·URL·숫자·textarea. 날짜·선택창·파일·라디오·체크박스는 별도 컨트롤로 유지.
- 오류 입력은 붉은 테두리, 비활성 입력은 흐리게, 읽기전용은 보조 글자색 유지.
- 카드 내부의 밀도와 배치, 장비 상태 색상, 달력, 페이지네이션은 다른 용도이므로 재설계하지 않음.
- 다크 모드는 기존 색상 체계를 유지하면서 새 입력 토큰의 대비만 보존. 이번 비교/선택 대상은 라이트.
- 공통 CSS는 globals.css의 `Approved component references, 2026-10-29` 블록에 모음.
