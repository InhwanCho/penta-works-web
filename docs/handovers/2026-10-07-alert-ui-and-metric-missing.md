# 알림 UI 및 항목별 연속 누락 알림

- 알림 확인을 첫 화면으로 배치. 수치 이상 / 병원 전체 수집 중단 / 측정항목 누락 / 콜드칠러 필터와 쉬운 설명.
- 병원별 설정을 수치 이상, 데이터 누락, 시간·휴일로 나눔. 병원 카드에서 시간·휴일 설정 바로 열기. 휴일은 날짜 수동 추가.
- 개인 측정항목마다 missingActive/missingThreshold 저장. 기존 JSON은 꺼짐/3회로 읽고, 최소3/최대288 검증. 수치 범위 사용 여부와 독립적.
- 실제 mrtb 최신 수집 행 기준으로 누락 횟수 계산. 빈 값/미측정/비정상 숫자 포함. 정상 값에서 초기화, 중복 시각은 한 번만 계산, 수집 주기의 1.5배보다 긴 공백에서 연속 기록 중단.
- 캐시 최신 시각과 읽은 수집 기록이 다르면 다음 주기에 다시 평가. 개인별 알림 제외 시간·날짜, 반복 및 명시적 확인 정책 그대로 적용.
- 별도 METRIC_MISSING 규칙·사건 사용. 병원 전체 중단이면 항목 평가와 발송 중지(전체 중단 알림 스위치가 꺼져 있어도 중복 항목 알림 없음). 대시보드와 개인 이력에 포함.
- 개인 settings_json에 저장하므로 새 DB migration 없음. 기존 설정과 이력 유지.
- 검증: backend141 tests, skip0/failure0 (격리 MariaDB10.11 DB 테스트 포함), frontend20 tests, lint/tsc/build 통과. 로컬UI 압력3회/잔량5회 저장·재열기, 모바일390px 가로 넘침 없음.
- 운영 데이터/수신 설정에 테스트 값을 저장하지 않음. 격리 테스트 DB 컨테이너 및 SSH 터널 정리.
