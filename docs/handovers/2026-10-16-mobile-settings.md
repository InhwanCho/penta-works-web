# Mobile settings navigation

Mobile navigation now includes Settings alongside Monitoring, Overview, Hospitals and Alerts. The mobile header keeps search and page context; profile and duplicate alert controls remain desktop-only. Settings groups account details, appearance, alert preferences and permission-controlled management links.

Manual logout is behind a collapsed Account access management disclosure on settings/account screens. Both device and all-device logout require a native confirmation dialog, defaulting focus to Cancel. Desktop profile logout also requires confirmation. Password-change session invalidation retains its existing behavior.

Development deployment only via dev branch Jenkins. No standalone tests or browser verification per user request; deployment compilation only.
