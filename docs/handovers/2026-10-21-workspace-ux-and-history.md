# 2026-10-21 — Small-screen usability and history retrieval

- Work/schedule text drafts use only account-scoped device localStorage, with seven-day recovery; no draft upload endpoint. Photo attachments continue to use the existing upload API. Schedule drafts preserve the original revision so stale restores receive the existing conflict response.
- Unsaved navigation: anchor/beforeunload plus cancellable Navigation API traversal; Safari fallback retains a same-URL history entry and returns on rejected back navigation. Draft restore/discard and schedule cancellation remain explicit. Hook tests simulate local persistence, restoration, account isolation and both traversal paths; actual browser visual checks were unavailable because browser access is disabled in Work settings.
- GET /workspace/legacy-history?from&to batches tenant snapshot/source-ID reads, filters dates and authorized sites, and returns per-site failures. Non-snapshot sites retain Office service fallback. Calendar no longer requests Office assets from each hospital.
- GET /workspace/hospital-history/{siteId}?page&size merges unconverted legacy history with server-limited workspace records. Deterministic ordering matches SQL for equal-date records, preventing page omissions. More loads 10 entries; old source snapshots remain intact.
- Schedules include lightweight authorized linkedRecords, removing the separate whole-workspace records fetch. Record saves/deletes invalidate schedules so links stay current.
- Fixed CSS text sizes now use rem (normal 16px root retains the existing appearance; large-text root enlarges them). Small-screen coarse-pointer hospital/history/menu actions have 44px minimum targets. Monitoring's notification-settings card uses a normal action label rather than a statistic-sized string.
- Validation: frontend production build; draft/navigation tests; isolated local MariaDB workspace tests including mixed legacy/new pagination, migration deduplication, date filtering, tenant/permission-safe linked records. No production business data modified by verification.
