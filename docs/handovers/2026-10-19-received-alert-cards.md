# Received alert cards

Cards prioritize hospital, plain-language problem, large measurement, configured range and occurrence time. Confirm and details/manage are the two primary actions. Snooze, threshold editing and delivery controls remain available inside details. Existing permissions, confirmation dialog and server actions are unchanged.

Synthetic mobile preview uses local Next frontend plus browser-intercepted API responses for three sample hospitals (high pressure, no data, low helium). No sample records are stored in any database or sent to providers. Captures under output/mobile-alerts-20261019. Explicit user request authorized mobile screenshots in this turn.

Deploy development only.
