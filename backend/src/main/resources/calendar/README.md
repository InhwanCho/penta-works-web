# 대한민국 공휴일 캘린더

`kr-holidays.json`은 2026-10-16 아래 공개 캘린더에서 받은 공휴일 전용 스냅샷입니다.

https://calendar.google.com/calendar/ical/ko.south_korea.official%23holiday%40group.v.calendar.google.com/public/basic.ics

서버는 시작 1분 후와 이후 24시간마다 같은 주소를 조회합니다. 실패하면 마지막 성공 데이터 또는 이 스냅샷을 유지합니다. 스케줄러의 알림 판단 경로에서는 외부 네트워크를 호출하지 않습니다. 임시공휴일 등 변경사항은 캘린더 제공자의 반영 시점에 따라 달라질 수 있으며 병원별 날짜 예외가 우선합니다.
